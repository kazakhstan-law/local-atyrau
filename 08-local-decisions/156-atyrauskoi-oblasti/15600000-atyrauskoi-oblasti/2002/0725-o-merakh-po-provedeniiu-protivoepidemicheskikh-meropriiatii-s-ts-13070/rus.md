# О мерах по проведению противоэпидемических мероприятий с целью недопущения заболевания холерой среди населения

В связи с неоднократным выделение в черте г. Атырау из реки Урал возбудителя холеры вирулентной формы, для организации и проведения противоэпидемических мероприятий по предотвращению заболевания населения РЕШИЛ:

<a id="p1"></a>

1. Областному управлению здравоохранения (Карасаева А.О.) направить средства из эпидфонда в сумме 942500 (девятьсот сорок две тысячи пятьсот) тенге на проведение противоэпидемических мероприятий, профилактического лечения и обследования группы риска.

<a id="p2"></a>

2. Областному финансовому управлению (Жантемиров Б.С.) осуществить своевременное финансирование на проведение противоэпидемических мероприятий.

<a id="p3"></a>

3. Областной санитарно-эпидимиологический станции (Зинуллин О.З.), областной противочумной станции (Хамзин С.Х.) организовать мероприятия, направленные на недопущение заболевания холерой среди населения, на проведение широкой санитарно-просветительской работы.

<a id="p4"></a>

4. Областному управлению здравоохранения обеспечить координацию и контроль за деятельностью медицинских организаций при проведении профилактических мероприятий.

<a id="p5"></a>

5. Контроль за исполнением данного решения возложить на Мурсалиеву Т.К. – заместителя акима области

**Первый заместитель акима области**
