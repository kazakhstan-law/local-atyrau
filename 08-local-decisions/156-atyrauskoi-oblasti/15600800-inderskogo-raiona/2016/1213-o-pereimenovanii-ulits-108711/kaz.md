# Көшелерге қайта атау беру туралы

«Қазақстан Республикасының әкімшілік-аумақтық құрылысы туралы» Қазақстан Республикасының 1993 жылғы 8 желтоқсандағы Заңының 14-бабының 4) тармақшасына, «Қазақстан Республикасындағы жергілікті мемлекеттік басқару және өзін-өзі басқару туралы» Қазақстан Республикасының 2001 жылғы 23 қаңтардағы Заңының 37-бабына және облыстық ономастика комиссиясының 2016 жылғы 2 тамыздағы қорытындысына сәйкес Жарсуат ауылдық округінің әкімі ШЕШІМ ҚАБЫЛДАДЫ:

<a id="p1"></a>

1. Индер ауданы, Жарсуат ауылдық округі, Құрылыс ауылындағы «Мұрат Мөңкеұлы» көшесі «Қылыш Кемалиевтің» есімімен қайта аталсын.

<a id="p2"></a>

2. Индер ауданы, Жарсуат ауылдық округі, Құрылыс ауылындағы «Механизатор» көшесі «Атамекен» атауымен қайта аталсын.

<a id="p3"></a>

3. Осы шешімнің орындалуын бақылауды өзіме қалдырамын.

<a id="p4"></a>

4. Осы шешім әділет органдарында мемлекеттік тіркелген күннен бастап күшіне енеді және ол алғашқы ресми жарияланған күнінен кейін күнтізбелік он күн өткен соң қолданысқа енгізіледі.
