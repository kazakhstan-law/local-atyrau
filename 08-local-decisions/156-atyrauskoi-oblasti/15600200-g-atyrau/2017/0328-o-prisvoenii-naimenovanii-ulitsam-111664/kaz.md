# Көшелерге атау беру туралы

«Қазақстан Республикасының әкімшілік-аумақтық құрылысы туралы» Қазақстан Республикасының 1993 жылғы 8 желтоқсанындағы Заңының 14-бабының 4)-тармақшасына, «Қазақстан Республикасындағы жергілікті мемлекеттік басқару және өзін-өзі басқару туралы» Қазақстан Республикасының 2001 жылғы 23 қаңтардағы Заңының 37-бабына сәйкес, Атырау ауылдық округінің әкімі ШЕШІМ ҚАБЫЛДАДЫ:

<a id="p1"></a>

1. Атырау қаласы, Атырау ауылдық округі, Атырау ауылындағы:

   №2 көшеге «Қисмет Мәсәлімовтің» есімі берілсін.

<a id="p2"></a>

2. Атырау қаласы, Атырау ауылдық округі, Атырау-1 ауылындағы:

   1) №5 көшеге «Фазыл Дахиевтің» есімі;

   2) №7 көшеге «Жәлел Иманғалиевтің» есімі;

   3) №8 көшеге «Нәби Әбілғазиевтің» есімі;

   4) №9 көшеге «Тарих Құмаровтың» есімі;

   5) №10 көшеге «Айбек Салиннің» есімі берілсін.

<a id="p3"></a>

3. Атырау қаласы, Атырау ауылдық округі, Жаңаталап ауылындағы:

   №1 көшеге «Сағынғали Садықовтың» есімі берілсін.

<a id="p4"></a>

4. Атырау қаласы, Атырау ауылдық округі, Жаңаталап-1 ауылындағы:

   №1 көшеге «Хасан Өтегеновтің» есімі берілсін.

<a id="p5"></a>

5. Атырау қаласы, Атырау ауылдық округі, Құрманғазы ауылындағы:

   №1 көшеге «Ізім Хамитовтың» есімі берілсін.

<a id="p6"></a>

6. Осы шешімнің орындалуын бақылау Атырау ауылдық округі әкімінің орынбасары Д.Әбішеваға жүктелсін.

<a id="p7"></a>

7. Осы шешім әділет органдарында мемлекеттік тіркелген күннен бастап күшіне енеді және ол алғашқы ресми жарияланған күнінен кейін күнтізбелік он күн өткен соң қолданысқа енгізіледі.

**Атырау ауылдық округінің әкімі**

**Ә.Құмаров**
