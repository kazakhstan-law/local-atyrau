# Көшелерге атау беру туралы

«Қазақстан Республикасының әкімшілік-аумақтық құрылысы туралы» Қазақстан Республикасының 1993 жылғы 8 желтоқсанындағы Заңының 14-бабының 4)-тармақшасына, «Қазақстан Республикасындағы жергілікті мемлекеттік басқару және өзін-өзі басқару туралы» Қазақстан Республикасының 2001 жылғы 23 қаңтардағы Заңының 37-бабына сәйкес, Қайыршақты ауылдық округінің әкімі ШЕШІМ ҚАБЫЛДАДЫ:

<a id="p1"></a>

1. Атырау қаласы, Қайыршақты ауылдық округі, Бесікті ауылындағы:

   №2 көшеге «Әбдір Егізбаевтың» есімі берілсін.

<a id="p2"></a>

2. Атырау қаласы, Қайыршақты ауылдық округі, Көктем тұрғын үй алабындағы:

   1) №12 көшеге «Жайсаң Жангереевтің» есімі;

   2) №14 көшеге «Сенебай Жұмахановтың» есімі;

   3) №15 көшеге «Құлжан Әділбековтің» есімі берілсін.

<a id="p3"></a>

3. Атырау қаласы, Қайыршақты ауылдық округі, Жұлдыз-3 тұрғын үй алабындағы:

   №19 көшеге «Әл-Фараби» есімі берілсін.

<a id="p4"></a>

4. Атырау қаласы, Қайыршақты ауылдық округі, Томарлы ауылындағы:

   Абай-2 көшесіне «Тәуелсіздіктің 25 жылдығы көшесі» атауы берілсін.

<a id="p5"></a>

5. Атырау қаласы, Қайыршақты ауылдық округі, Томарлы-2 ауылындағы:

   №14 көшеге «Байдолла Ешмұхамбетовтің» есімі берілсін.

<a id="p6"></a>

6. Осы шешімнің орындалуын бақылау Қайыршақты ауылдық округі әкімінің орынбасары А.Жайбосыновқа жүктелсін.

<a id="p7"></a>

7. Осы шешім әділет органдарында мемлекеттік тіркелген күннен бастап күшіне енеді және ол алғашқы ресми жарияланған күнінен кейін күнтізбелік он күн өткен соң қолданысқа енгізіледі.

**Қайыршақты ауылдық округінің әкімі**

**Ш.Қалиев**
