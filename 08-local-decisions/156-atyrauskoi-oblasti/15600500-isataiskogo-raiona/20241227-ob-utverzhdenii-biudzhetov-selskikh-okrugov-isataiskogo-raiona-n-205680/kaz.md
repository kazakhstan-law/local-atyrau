# 2025-2027 жылдарға арналған Исатай ауданының ауылдық округтерінің бюджеттерін бекіту туралы

> *Ескерту. 01.01.2025 бастап қолданысқа енгізіледі - осы шешімнің 11 тармағымен.*

Қазақстан Республикасының Бюджет кодексінің 9-1 бабына, «Қазақстан Республикасындағы жергілікті мемлекеттік басқару және өзін-өзі басқару туралы» Қазақстан Республикасының Заңының 6-бабының 1 тармағының 1) тармақшасына сәйкес және аудан әкімдігімен ұсынылған 2025-2027 жылдарға арналған ауылдық округтер бюджет жобасын қарап, Исатай аудандық мәслихаты ШЕШІМ ҚАБЫЛДАДЫ:

1. Аққыстау ауылдық округінің 2025-2027 жылдарға арналған бюджеті тиісінше 1, 2, 3 қосымшаларға сәйкес, оның ішінде 2025 жылға келесідей көлемдерде бекітілсін:

   1) кірістер – 515 688 мың теңге, оның ішінде:

      салықтық түсімдер – 52 411 мың теңге;

      салықтық емес түсімдер - 671 мың теңге;

      негізгі капиталды сатудан түсетін түсімдер - 0 теңге;

      трансферттер түсімі – 462 606 мың теңге.

   2) шығындар – 515 688 мың теңге.

   3) таза бюджеттік несиелендіру - 0 теңге, оның ішінде:

      бюджеттік несиелер - 0 теңге;

      бюджеттік несиелерді өтеу - 0 теңге.

   4) қаржы активтерімен операциялар бойынша сальдо - 0 теңге, оның ішінде:

      қаржы активтерін сатып алу - 0 теңге;

      мемлекеттің қаржы активтерін сатудан түсетін түсімдер - 0 теңге.

   5) бюджет тапшылығы (профициті) - 0 теңге.

   6) бюджет тапшылығын қаржыландыру (профицитін пайдалану) - 0 теңге, оның ішінде:

      қарыздар түсімі - 0 теңге;
