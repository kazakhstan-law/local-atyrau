# Зинеден селосындағы "Затон", Амангелді елді мекеніндегі "Родина" көшелерінің атауын өзгерту туралы

Қазақстан Республикасының 1993 жылғы желтоқсанында N 4200 "Қазақстан Республикасының әкімшілік-аумақтық құрылысы туралы" Заңының 14-бабы 2 тармағына және аудандық ономастикалық комиссияның 2008 жылғы 17 сәуірдегі ұйғарымына сәйкес ШЕШЕМІН:

<a id="p1"></a>

1. Забурын селолық округінің елді мекенінің "Родина" көшесі "Ақшағала" көшесі болып қайта аталсын.

<a id="p2"></a>

2. Зинеден селосының "Затон" көшесі "Толқынды" көшесі болып қайта аталсын.

<a id="p3"></a>

3. Осы шешімнің орындалуын бақылау Забурын селолық округі әкімі аппаратының бас маманы Ш. Құрмановаға жүктелсін.

<a id="p4"></a>

4. Осы шешім алғаш рет ресми жарияланған күннен бастап он күнтізбелік күннен соң қолданысқа енгізіледі.

   *Забурын селолық округі әкімі Б. Құсаинов*
